I am a text file meant to test commits in git. 
Here are some standard git commands : 
git status : gives status of changes in the project 
git add ... : adds file to be committed 
    - file.name : just that file 
    - . : all modified files
git restore ... : restores to a previous version
git commit -m "" : commits all add files with a message

Now it is important to learn how to push to github: 
- make a repository on github and run these lines to push a existing git repository on gitub. 
git remote add origin https://github.com/Dawnoboo/testPushToGitHub.git
git branch -M main
git push -u origin main

Finally : 
In order to update files on the github repository we need to run : 
git push

In order to make changes in a github repository we need to : 

edit a file 
git add a file 
git commit a file 
git push a file
